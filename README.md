# Quiz App (Python CLI)

A simple command-line quiz application built using Python.

## Features
- Multiple-choice quiz
- Score tracking
- Case-insensitive answer checking
- Final score display

## Concepts Used
- Lists
- Dictionaries
- Loops
- Nested loops
- Conditionals
- String methods
- User input

## How to Run

```bash
python main.py
```

## Sample Questions
- Capital of India
- AI/ML language
- Red Planet
- General knowledge questions

## Learning Purpose

This project was built to practice Python fundamentals and improve logic-building skills.
